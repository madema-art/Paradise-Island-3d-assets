# Monkey asset package

Long-tailed-macaque-like monkey for the Paradise Island Three.js game: one organic skinned mesh, 2048² painted PBR texture set, 102-joint rig, 41 baked animation clips and a coconut prop. Generated by `tools/monkey/` (`build_all.sh`); do not edit the GLBs by hand, rebuild them. See `docs/MONKEY_INTEGRATION.md` for the integration guide.

## Specification

- Body mesh: 60,352 triangles in LOD0 (incl. eyes/lids), 35,850 glTF vertices; 102 joints; 4 influences per vertex.
- Materials: MonkeyFur (albedo, tangent-space normal, ORM; sheen), MonkeyEye, MonkeyLid, MonkeyLidEdge. One 2048² UV atlas for the body.
- Orientation: faces +Z in glTF (Y-up), units metres, ~0.46 m head-body, ~0.95 m with tail.
- Khronos glTF validator: **0 errors**, 8 warnings (runtime-generated tangents; skinned mesh nodes not at root: benign).
